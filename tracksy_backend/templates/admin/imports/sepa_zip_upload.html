Import SEPA data from ZIP file

Expected format

The ZIP must contain the following files in SEPA format (columns separated by |):

  • comercio.csv — supermarket chains (id_bandera, comercio_bandera_nombre, …)
  • sucursales.csv — branches and opening hours (id_sucursal, sucursales_nombre, …)
  • productos.csv — products, brands and prices (id_producto, productos_descripcion, productos_precio_lista, …)
Existing records will be updated (upsert) based on the file identifiers. Processing may take a few seconds depending on the ZIP size.
